### Task A.0 — Wire GH Release auto-draft (Codex round-1 HIGH #6)

The plan's claim that GH Release is "auto-drafted" requires an explicit GitHub Actions step — `pypa/gh-action-pypi-publish` only handles PyPI. This task lands the missing step.

**Files:**
- Modify: `.github/workflows/ci.yml`

- [ ] **Step 1:** In `.github/workflows/ci.yml`, the `publish` job (which currently triggers on `v*` tags) needs an additional step to draft the GH Release from the CHANGELOG entry. Add after the `Publish` step:

```yaml
      - name: Extract changelog section for this tag
        id: changelog
        run: |
          python - <<'PY'
          import re
          import os
          from pathlib import Path

          tag = os.environ["GITHUB_REF_NAME"]  # e.g. "v0.1.0" or "v0.1.0rc2"
          version = tag.lstrip("v")
          changelog = Path("CHANGELOG.md").read_text()
          # Find the section for [version]
          pattern = rf"^## \[{re.escape(version)}\][^\n]*\n(.*?)(?=^## \[|\Z)"
          m = re.search(pattern, changelog, re.DOTALL | re.MULTILINE)
          body = m.group(1).strip() if m else f"Release {version}"

          with open(os.environ["GITHUB_OUTPUT"], "a") as out:
              # Multi-line output via heredoc
              out.write(f"body<<EOF\n{body}\nEOF\n")
          PY

      - name: Create GitHub Release
        uses: softprops/action-gh-release@v2
        with:
          tag_name: ${{ github.ref_name }}
          name: ${{ github.ref_name }}
          body: ${{ steps.changelog.outputs.body }}
          draft: true
          prerelease: ${{ contains(github.ref_name, 'a') || contains(github.ref_name, 'b') || contains(github.ref_name, 'rc') }}
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```
